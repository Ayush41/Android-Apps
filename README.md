# Android Lab Apps

This repository contains my college lab work, including basic practice project apps developed using Android Studio, Java, and XML. These projects demonstrate various fundamental concepts and techniques in Android development.

## Introduction
This repository is a collection of Android applications created as part of my college lab work. Each project focuses on different aspects of Android development, such as UI design, data storage, networking, and more. The goal is to provide a hands-on learning experience and build a solid foundation in Android programming.

## Projects
1. **Calculator App**: A simple calculator application that performs basic arithmetic operations.
2. **Implicit-Intent**: A simple basic app that performs implicit intent of android.

## Installation
To run any of the projects in this repository, follow these steps:
1. Clone the repository:
    ```sh
    git clone https://github.com/Ayush41/Android-Apps.git
    ```
2. Open the project in Android Studio.
3. Build and run the project on an emulator or a physical device.
